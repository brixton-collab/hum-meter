# The Hum Meter

Hum for five seconds. Get your note, your wobble, and whether it cracked.

Runs entirely in the browser — no audio is uploaded, no signup, no app.

Scoring is calibrated against real measured hums, not clinical sung-vowel
reference values. See `Content/hum-lab/` in the source vault for the
calibration pipeline (`hum-score.py`, `hum-lab.py`, `hum-test.py`).
